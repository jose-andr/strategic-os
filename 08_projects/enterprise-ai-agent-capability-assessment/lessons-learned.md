# Enterprise AI Agent Capability Assessment — Lessons Learned

## Purpose

Capture reusable lessons from real enterprise-agent use.

## Current lessons

### L001 — Allocate enterprise AI by native strength

**Status:** Emerging

Generic chat overlap matters less than which organisational system an agent can access natively and governably.

### L002 — Restricted agents can still create leverage

**Status:** Emerging

Retrieval, summarisation, preparation and structured handoff can remove recurring administration even without autonomous write access.

### L003 — Policy retrieval needs provenance

**Status:** Emerging

For governance-sensitive questions, a generated answer is insufficient unless the authoritative organisational source can be identified.

### L004 — Duplicate agents create management debt

**Status:** Hypothesis

Multiple agents solving the same task across overlapping platforms are likely to increase configuration and reconciliation burden.

## Review rule

Promote a lesson only when it is supported by repeated use or clear evidence, privacy-safe, reusable and useful for future decisions.
