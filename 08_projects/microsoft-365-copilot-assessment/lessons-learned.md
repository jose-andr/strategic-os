# Microsoft 365 Copilot Capability Assessment — Lessons Learned

## Purpose

Capture reusable lessons that emerge from real capability testing.

Only record lessons once repeated use or clear evidence makes them durable enough to reuse.

Potentially reusable lessons may later move to `05_lessons_learned/`.

## Current lessons

### L001 — Product availability is not tenant availability

**Status:** Emerging

**Lesson:**  
Public product capability should not be treated as evidence that a feature is available, licensed, enabled, approved or useful in the organisational environment.

**Implication:**  
Validate tenant reality before designing an operating model around a Microsoft 365 Copilot capability.

---

### L002 — Operational leverage includes maintenance cost

**Status:** Emerging

**Lesson:**  
A capability that saves time during use may still create negative value if it requires frequent configuration, reconciliation, monitoring or manual correction.

**Implication:**  
Assess ongoing management burden alongside functional usefulness.

---

### L003 — Retrieval quality depends on source quality

**Status:** Hypothesis

**Lesson:**  
Copilot cannot reliably compensate for unclear ownership, duplication, outdated information or weak source-of-truth discipline.

**Implication:**  
Knowledge retrieval tests should assess both Copilot performance and the quality of the underlying organisational information environment.

## Review rule

Promote an emerging lesson only when:

- repeated testing supports it;
- the lesson is reusable beyond this assessment;
- it is safe to retain;
- it does not depend on confidential organisational detail; and
- it improves future decisions or operating practice.
